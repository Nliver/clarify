# Releases

This page records the major reader-visible changes in Clarify. When a release requires action, its entry links to a durable guide or reference page.

Clarify has not reached `1.0.0` yet. During the `0.x` phase, APIs and configuration formats may change without full backward compatibility. Pin the CLI version used by each project and review the release notes before upgrading.

<Release version="v0.12.0">

### Added

- Added structured `navigation.menus` entries for page links, external links, and nested menus.
- Added Blog and Releases as first-class page menus in the Clarify documentation.

### Changed

- Replaced the old top-navigation `navigation.links` configuration with `navigation.menus`.
- Removed the redundant `external` flag; external URLs are detected from their `href`.
- Renamed shared link types to generic `LinkConfig` types for banners and footers.

### Breaking changes

- Projects using `navigation.links` or `external` must update their configuration before upgrading.

</Release>

</Release>
