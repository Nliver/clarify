# 版本列表

这里记录 Clarify 面向文档作者和读者的主要版本变化。需要操作说明时，版本条目会链接到长期维护的指南或参考页面。

Clarify 目前尚未达到 `1.0.0`。在 `0.x` 阶段，API 和配置格式仍可能发生变化，且不保证完整的向后兼容。请为每个项目锁定所使用的 CLI 版本，并在升级前阅读版本说明。

<Release version="v0.12.0">

### 新增

- 新增结构化的 `navigation.menus`，支持页面链接、外部链接和嵌套菜单。
- 将博客和版本列表作为 Clarify 文档中的页面菜单加入导航。

### 变更

- 使用 `navigation.menus` 替代旧的顶部导航 `navigation.links` 配置。
- 移除冗余的 `external` 字段，外部 URL 会根据 `href` 自动识别。
- 将 Banner 和 Footer 使用的共享链接类型重命名为通用的 `LinkConfig` 类型。

### 不兼容变更

- 使用 `navigation.links` 或 `external` 的项目需要在升级前更新配置。

</Release>

<Release version="v0.11.12">

- 新增分组级 `visible` 规则，可将文档从公开导航中隐藏，同时保留直接链接访问和完整的组内导航。
- 新增分组级 `searchable` 配置，可将继承该配置的页面排除在内建搜索、Pagefind 和 MCP 搜索索引之外。

</Release>
